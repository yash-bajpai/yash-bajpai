### 01 / DocGraph AI
**Full-Stack GraphRAG Document Intelligence**

A hybrid document intelligence system combining semantic retrieval with knowledge graph traversal.

- Combined dense HNSW vector search with Neo4j graph traversal.
- Built an asynchronous, multi-agent FastAPI backend.
- Designed a write-time entity resolution engine to canonicalize entities across documents.
- Migrated inference workflows to the Gemini Batch API to address memory and rate-limit issues.

`Python` `FastAPI` `HNSW` `Neo4j` `GraphRAG` `Gemini API`

### 02 / Stress Intelligence Platform
**Distributed Analytics & Machine Learning**

A data-processing and predictive analytics pipeline for identifying high-risk patterns in student records.

- Processed 130K+ weekly records using PySpark and Spark SQL.
- Used partitioned Parquet storage to reduce analytical query latency by 60%.
- Engineered temporal entropy, drift, acceleration, and volatility features.
- Trained a class-balanced Random Forest model achieving 88% recall on high-risk cases.
- Built an incremental inference engine for intervention alerts in under one second.

`PySpark` `Spark SQL` `Parquet` `scikit-learn` `Random Forest`

### 03 / AEGIS-ZONE
**Zero-Trust Workstation Security**

A full-stack workstation security prototype combining biometric verification, wireless intrusion detection, and real-time access control.

- Integrated FastAPI, Next.js, React, ESP32, and WebSockets.
- Implemented session-key generation and invalidation using AES and SHA3-256.
- Built live monitoring and automated workstation lockdown workflows for biometric failures and unauthorized wireless threats.

`FastAPI` `Next.js` `React` `ESP32` `WebSockets` `Security`

### 04 / Industrial Alarm Analytics
**Maruti Suzuki India Limited · Software Engineering Internship**

A manufacturing alarm analytics platform designed to turn industrial alarm data into actionable operational insights.

- Built a full-stack application using Node.js, Express.js, and MongoDB.
- Automated Excel-to-MongoDB ingestion for 10,000+ alarm records through REST APIs.
- Integrated MongoDB and PostgreSQL in a polyglot data architecture.
- Developed KPI dashboards, Pareto analysis for downtime, and an Isolation Forest model for abnormal alarm patterns.

`Node.js` `Express.js` `MongoDB` `PostgreSQL` `ETL` `Isolation Forest`

### 05 / Madras High Court Cause List Parser
**AI Blocks · Document Data Extraction**

A document parsing pipeline built to extract structured case information from large court cause-list PDFs without OCR or LLM dependencies.

- Processed PDFs containing 4,000+ cases.
- Used Document Anchor Graph Parsing, spatial tokenization, and graph segmentation.
- Achieved 97–99% extraction accuracy with processing times of 2–4 seconds per PDF.

`Python` `Document Parsing` `Graph Segmentation` `Data Extraction`
